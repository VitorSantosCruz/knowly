# Code of Conduct

## Our commitment

As contributors and maintainers of this project, we commit to maintaining a
respectful, collaborative, harassment-free environment for everyone,
regardless of experience, gender identity, sexual orientation, disability,
physical appearance, ethnicity, religion, or nationality.

## Expected standards

- Respectful, constructive communication in issues, PRs, and code reviews.
- Criticism should be about the code/idea, never about the person.
- Accept feedback graciously and admit mistakes when pointed out.
- Prioritize what's best for the project and the team.

## Unacceptable behavior

- Offensive language or imagery, public or private harassment.
- Personal attacks, insults, or derogatory comments.
- Publishing others' private information without consent.
- Any conduct that would reasonably be considered inappropriate in a
  professional setting.

## Enforcement

Violations can be reported to the project maintainer
(knowly-conduct@conectabyte.com.br). All complaints will be reviewed and
investigated fairly. The maintainer has the right to remove, edit, or
reject comments, commits, code, issues, and other contributions that are
not aligned with this code of conduct.

## Scope

This code of conduct applies to all project spaces (repository, issues,
PRs) and in public spaces when an individual is representing the project.
